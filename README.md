# StudyFlow — Student Planner (SaaS-style UI)

A responsive student planner built with HTML, CSS, and vanilla JavaScript. It is a front-end project suitable for a student portfolio or GitHub repository.

## Features
- Dashboard with task counters
- Add, complete, filter, and delete tasks
- Assign a subject and due date to each task
- Create and remove study schedule entries
- Set and check off study goals
- Responsive layout for desktop, tablet, and mobile
- Saves data in the browser using `localStorage`

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.

No installation or build tools are required.

## Deploy with GitHub Pages
1. Create a GitHub repository named `student-planner-saas`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Wait for deployment and open the Pages URL shown by GitHub.

## SaaS model note
This is a SaaS-inspired front-end prototype. It does not include real accounts, cloud sync, payments, or a backend database. Those would need to be added separately for a production multi-user SaaS product.
