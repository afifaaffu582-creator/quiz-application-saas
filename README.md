# SmartQuiz — Quiz Application SaaS Demo

A responsive student quiz application built with HTML, CSS, and vanilla JavaScript. This starter project demonstrates a simple SaaS-style learning interface.

## Features
- Multiple-choice quiz with 5 questions
- Instant answer feedback and explanations
- Progress bar and score summary
- Student dashboard with completed quiz count, best score, and latest score
- LocalStorage-based demo history
- Responsive desktop and mobile layout

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a web browser.

No build tools or dependencies are required.

## GitHub Pages deployment
1. Create a GitHub repository named `quiz-application-saas`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Important note about the SaaS model
This is a front-end demonstration, not a production multi-user SaaS service. LocalStorage data stays in the current browser. For real accounts, shared quiz creation, and cloud-synced results, connect a backend such as Firebase or Supabase and configure authentication, database security rules, and role-based access.
